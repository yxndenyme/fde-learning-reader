# FDE 学习计划 · 在线阅读

在线阅读：https://yxndenyme.github.io/fde-learning-reader/

12 个单元完整正文，支持全文搜索、目录导航、明暗主题、打印及手机阅读。`index.html` 是自包含的离线文件，可以下载后直接打开。

本仓库只保存授权公开的学习正文生成结果。私人学习进度、个人记录、完整题库与实操目录文件不在本仓库。正文中的配套材料链接需要源库访问权限。

## 更新

正文在私有源仓库中维护。主分支正文变化后自动生成并推送到这里，再通过 GitHub Pages 发布。每天另有自动核对任务；失败时保留上一版。不要在此仓库手工修改正文，否则会被下一次生成覆盖。

`version.json` 记录对应源提交、公开正文内容指纹和文件清单，可核对同步情况。已打开的网页需要刷新；下载的离线副本不会自动变化。
